# Resume Analyzer

## About the Project
Resume Analyzer is a web-based application that analyzes resumes and compares them with job descriptions. It helps job seekers understand how well their resumes match job requirements.

## Features
- Upload resumes in PDF, DOCX, or TXT format.
- Enter a job description.
- Analyze resume and job description matching.
- Identify relevant skills.
- Display resume matching results.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Structure
- app.py - Backend application
- index.html - Main HTML page
- templates/ - HTML templates
- static/ - CSS and JavaScript files
- requirements.txt - Python dependencies
- skills_data.py - Skills data

## How to Run

1. Clone the repository.
2. Install the required dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open the local URL displayed in the terminal.

## Project Goal
To help job seekers improve their resumes by identifying how closely their skills and experience match a job description.
